# Paper used by this experiment

The accepted ICML 2026 Time-PEFT paper used as research context is:

Jihye Na, Patara Trirat, Chanyoung Park, and Jae-Gil Lee, “Time-PEFT: Temporal
and Multichannel Complexity-Based Fine-Tuning for Time-Series Foundation Models,”
OpenReview forum `n8seTOinYs`.

Canonical entry: <https://openreview.net/forum?id=n8seTOinYs>

Download the PDF from the canonical entry when needed. Local PDF copies under
this directory are ignored so the repository keeps citation provenance without
vendoring the paper.

The repository implementation is independent and is not official author code. Keep the
PDF citation/provenance separate from implementation claims.
